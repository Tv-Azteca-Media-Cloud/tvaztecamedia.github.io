ADR-007 Accepted Core Layer
OmniStudio Acceptable as Part of Media Cloud Standard Package
TV Azteca · Salesforce Delivery Platform · ADP Whitelabel
Fecha: 2026-05-14 Estado: Accepted Layer: Core / Base Template
Context

ADR-002 establishes LWC + Apex as the primary extensibility path and designates OmniStudio as a last resort — only when it brings a clear, justified benefit that LWC + Apex cannot provide.

The Media Cloud Ad Sales package (installed in the crp-media org) includes OmniStudio as part of its standard runtime. Several standard Media Cloud flows and guided processes are built on OmniStudio (OmniScripts, Integration Procedures). Users assigned the Media Cloud Runtime permission set receive OmniStudio User automatically. This is not a custom development choice — it is the standard platform behavior for this product.

Decision

OmniStudio components that are part of the standard Media Cloud package are acceptable and do not require ADR-002 justification. They are treated as platform configuration, not custom development.

Custom OmniStudio development — any OmniScript, FlexCard, or Integration Procedure authored by the project team beyond what the Media Cloud package delivers — remains subject to ADR-002. Before building a custom OmniStudio component, the Standard-First Challenge Gate in refine-story-media must confirm that LWC + Apex cannot meet the requirement.

Alternatives Considered
Applying ADR-002 strictly to all OmniStudio, including standard Media Cloud flows
Rejected — this would require replacing standard Media Cloud functionality with custom LWC, increasing delivery risk and diverging from the supported upgrade path.
Blanket OmniStudio exception for Media Cloud projects
Rejected — this would open the door to custom OmniStudio development without challenge, reintroducing the complexity ADR-002 was designed to prevent.
Consequences
  • The refine-story-media skill must not flag standard Media Cloud OmniStudio flows as ADR-002 violations.
  • Any proposed custom OmniStudio artifact in a task decomposition must be challenged against Standard-First before appearing in a Jira task.
  • When reviewing a PR that includes OmniStudio metadata, the reviewer must verify it is either a standard package artifact or has passed the Standard-First Gate with documented justification.
  • This ADR applies only to Media Cloud projects. Comms Cloud and other projects remain under ADR-002 without exception.
